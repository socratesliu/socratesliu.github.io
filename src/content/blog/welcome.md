你好,欢迎来到我的个人博客。

这个站点用来记录我的**技术实践**、**阅读笔记**和**日常思考**。相比碎片化的社交动态,我更愿意在这里写一些能够沉淀下来的东西 —— 一段排查了很久的 bug、一个反复用到的技巧、或者读完之后想记下的观点。

## 这个博客的特点

- **内容以 Markdown 编写** —— 所有的文章都是纯文本文件,可以用任何编辑器写,也可以随时用 Git 版本管理
- **完全静态** —— 没有数据库、没有服务端逻辑,访问速度很快
- **按主题组织** —— 每篇文章都可以打上多个标签,方便横向浏览同一主题下的所有内容
- **可订阅** —— 通过 [RSS](/rss.xml) 就能在有新文章时收到通知

## 为什么用 Astro 构建

Astro 的内容集合功能允许我在 `src/content.config.ts` 里用 Zod schema 定义文章的结构:

```ts
const blog = defineCollection({
  loader: glob({ base: './src/content/blog', pattern: '**/*.md' }),
  schema: z.object({
    title: z.string(),
    description: z.string(),
    pubDate: z.coerce.date(),
    tags: z.array(z.string()).default([]),
  }),
});
```

这样一来,任何一篇文章漏写标题或日期,在构建时就会直接报错,而不是等到上线后才发现问题。类型安全在这里不是锦上添花,而是让「写错字段」这件事尽早暴露。

## 接下来会写什么

技术笔记会是主要内容,大概会围绕这几个方向:

1. 后端开发中踩过的坑与踩坑记录
2. 工具链与工程效率
3. 值得反复阅读的书籍与文章

如果你对其中某个话题特别感兴趣,可以到[标签页](/tags/)看看,或者在文章下方留言讨论 —— 那里的评论直接存放在 GitHub Discussions 里,不需要额外的账号系统。
